# 🚀 create-repo 脚本（Git Server 专用）

保存为：

```bash
/usr/local/bin/create-repo
```

---

## 📜 脚本内容

```bash id="x7m2qa"
#!/bin/bash

# ==============================
# Git 仓库自动创建脚本（Git Server）
# ==============================

# Git 用户和仓库目录
GIT_USER="git"
REPO_BASE="/home/git/repo"

# 获取仓库名称
REPO_NAME="$1"

# 检查参数是否为空
if [ -z "$REPO_NAME" ]; then
    echo "❌ 错误：请提供仓库名称"
    echo "用法：create-repo <repo_name>"
    exit 1
fi

# 自动补全 .git 后缀
if [[ "$REPO_NAME" != *.git ]]; then
    REPO_NAME="${REPO_NAME}.git"
fi

REPO_PATH="$REPO_BASE/$REPO_NAME"

echo "=============================="
echo " 创建 Git 仓库: $REPO_NAME"
echo "=============================="

# 检查仓库是否已存在
if [ -d "$REPO_PATH" ]; then
    echo "❌ 仓库已存在：$REPO_PATH"
    exit 1
fi

# 创建裸仓库
sudo -u $GIT_USER git init --bare "$REPO_PATH"

# 设置权限
chown -R $GIT_USER:$GIT_USER "$REPO_PATH"
chmod -R 755 "$REPO_PATH"

echo "=============================="
echo "✅ 仓库创建成功"
echo "路径: $REPO_PATH"
echo ""
echo "📌 客户端使用方式："
echo "git clone git-server:$REPO_NAME"
echo "=============================="
```

# 🔧 安装步骤

## 1️⃣ 创建脚本文件

```bash id="n8p3ld"
sudo vim /usr/local/bin/create-repo
```

粘贴上面的内容

---

## 2️⃣ 添加执行权限

```bash id="k4q9lm"
sudo chmod +x /usr/local/bin/create-repo
```

---

## 3️⃣ 确保 git 用户目录存在

```bash id="v2s8ax"
mkdir -p /home/git/repo
chown -R git:git /home/git
```

# 🚀 使用方法

## ✔ 创建仓库

```bash id="q9m1zk"
create-repo test
```

或：

```bash id="a7x2wp"

```

---

会生成：

```text id="l3v9kd"
/home/git/repo/test.git
```

---

## ✔ 客户端直接使用


# ⚠️ 常见优化建议（很重要）

## 🔐 1. 限制权限（更安全）

```bash id="z6kq1p"
chmod 750 "$REPO_PATH"
```

## 🧩 2. 自动初始化 README（可选增强）

可以加：

```bash id="t8v1md"
echo "# $REPO_NAME" | sudo -u $GIT_USER tee "$REPO_PATH/description"
```

可以加：
