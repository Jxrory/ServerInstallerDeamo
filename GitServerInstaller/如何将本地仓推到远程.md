# 🚀 一、服务器端先准备好裸仓库（必须）

请先参考[如何创建裸仓教程](./创建裸仓教程.md)

在 Git Server 上：

```bash
create-repo test
```

---

# 🚀 二、本地已有仓库上传（核心步骤）

假设你本地已经有一个项目：

```bash
cd my_project
git init
git add .
git commit -m "init"
```

---

# 1️⃣ 添加远程仓库（重点）

## ✔ 使用 SSH config（推荐）

```bash
git remote add origin git-server:repo/test.git
```

---

# 2️⃣ 推送代码到服务器

## 首次推送（最关键）

```bash
git push -u origin main
```

---

# 🚀 三、如果仓库已经有历史（常见情况）

如果你本地已经有 commit：

```bash
git push -u origin main --force
```

⚠️ 注意：

* `--force` 会覆盖远端内容（慎用）

---

# 🚀 四、验证是否成功

服务器上检查：

```bash
cd /home/git/repo/test.git
git log
```

或者本地重新 clone：

```bash
git clone git-server:/home/git/repo/test.git
```

---

# ⚠️ 五、最常见问题（非常重要）

## ❌ 1. Permission denied (publickey)

原因：

* SSH key 没配好
* 或没加入 authorized_keys

解决：

```bash
ssh git-server
```

如果失败，先修 SSH。

---

## ❌ 2. repository not found

原因：

* 路径写错

正确格式：

```bash
git-server:/home/git/repo/test.git
```

❌ 不要少 `/home/git/...`

---

## ❌ 3. remote rejected

原因：

* 远端不是 bare 仓库

必须是：

```bash
git init --bare
```

---

# 🚀 六、推荐标准工作流（企业级）

## ✔ 初始化仓库

```bash
git init
git add .
git commit -m "init"
```

## ✔ 绑定远程

```bash
git remote add origin git-server:/home/git/repo/project.git
```

## ✔ 推送

```bash
git push -u origin main
```
